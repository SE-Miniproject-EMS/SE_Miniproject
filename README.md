# Event Management System

A BTech Software Engineering mini-project for organizing and attending events. Organizers can publish events, track registrations, and export reports. Attendees can discover events, register or join a waitlist, and check in with a digital ticket. The app uses React, Express, and SQLite. Payments and refunds are simulated for demonstration.

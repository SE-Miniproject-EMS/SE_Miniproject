# Issue #33 — Event-creation usability study

**Requirement:** NFR-USAB-01 — an organizer without a technical background can create and publish an event in under five minutes without external assistance.

**Current result: NOT RUN / NOT VERIFIED.** No representative participant was available for this review. No participant observations or completion-time results are claimed. The checklist below is ready for the team to use when a participant is available.

## Repeatable task

Give the participant this task, without coaching or demonstrating the workflow first:

> You are organizing an event. Create a new event with the details on the test card, publish it, and tell the facilitator when it is publicly available.

The facilitator should prepare one valid test card before the session with a title, description, category, venue, start/end date and time, capacity, and ticket price appropriate to the selected free or paid flow. Use test data only. Keep the same card and starting account state for each session.

## Session procedure

1. Recruit a first-time or infrequent event organizer who does not have technical experience. Record only a participant code and a broad relevant experience note; do not collect unnecessary personal data.
2. Confirm the participant understands the task and obtain consent before any screen/audio recording. Recording is optional; written observations are sufficient.
3. Start the timer when the participant opens the event-creation flow. Stop it when the participant successfully publishes the event and can identify that it is publicly available.
4. Do not assist during the timed task. If the participant requests help, provide only the help necessary to continue, record it, and classify the unaided target as not met for that session.
5. Record success/failure, elapsed time, assistance, validation errors, blockers, and participant comments. Do not record credentials or sensitive account data.
6. Reset or remove the test event through the normal application workflow before another session. Do not delete unrelated project data.
